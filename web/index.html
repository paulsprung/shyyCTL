Scan

Full/quick spin each fan channel up, read its tachometer, and read the hub's per-channel accessory ID to identify the fan model (and with it, the real LED count) where possible. Silent skips the fan spin-up entirely - it only reads accessory IDs, so it can't confirm an unrecognised channel is actually empty, just quieter and faster. All three resize the matching OpenRGB hub zones and read mobo/RAM afterwards, so RGB control on the RGB page works right after.
